CANNBOT Connect reuses CANNWork's existing opencode sign-in, keeps the model roster live, and
enables image input only for the exact models measured to read images.

After installation, open **Settings → CANNBOT** (or the CANNBOT card at the bottom of the
Models page) to view credential state, refresh the roster, toggle per-model image support, and
edit the image/capacity budgets. Changes apply without a restart.
